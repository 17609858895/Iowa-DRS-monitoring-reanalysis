# Source attribution and reuse

This repository contains the reanalysis code accompanying **Separating temporal shortcuts from spectral information in full scale anaerobic codigestion monitoring**. Code contact: Chong Liu.

The public source dataset is **Dataset and Code for Rapid In-line Monitoring of Full-Scale Anaerobic Co-Digestion Using Diffuse Reflectance Spectroscopy and Machine Learning**, by Zoe A. M. Kramin and Craig L. Just, University of Iowa, DOI: https://doi.org/10.25820/data.008042. Its associated paper is https://doi.org/10.1021/acs.energyfuels.5c04529.

The dataset README assigns CC BY 4.0 to its data and documentation and MIT to its two original companion Python scripts. Those data and companion scripts are not redistributed in this code-only repository. `download_public_data.py` retrieves the official attachments to an ignored local directory and retains their official README. Consult that README for the original attribution and full license terms.

No separate reuse license for the reanalysis code is asserted here. Third-party Python packages retain their respective licenses. No University logo, manuscript, supplementary document, generated image, private credential, or precomputed scientific output is included.
